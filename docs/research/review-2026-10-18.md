# Correctness review of M1 (2026-10-18)

An independent read-only review of the M1 code after the suite passed. Every
item below was confirmed with a counterexample (scratch files under the
session's scratchpad `review/`). The status of each fix is tracked in bean
genclj-9yrv (this document's checklist).

## Confirmed bugs

1. **Batched mode takes one branch for every particle on host predicates.**
   `(= k 0)` on an [N] array is plain `false`, so `if` never raises the
   batched-branch error. `case`, `get` and `contains?` behave the same. Batched
   IS on `mu (if (= k 0) 0.0 3.0)` gave log-ml −5.419 (all particles in the
   else branch), against −1.607 scalar and −1.601 exact.
2. **Batched elementwise sites with event axes are wrong.** Shape-based
   batching pairs an [N] per-particle parameter with the last axis of a [3]
   value. For a shared observation `ys` = [0.5 1 1.5] under `(normal mu 1)`,
   particle i was scored only against y_i at N = 3, and N = 4 threw a broadcast
   error with no fallback. `b/simulate` returned [3] instead of [3 3].
3. **Changing the generative function at a retained splice address** hands
   the old sub-trace to the new one. The new distribution kept g1's return
   value 7.0; the weights and discards were wrong; g1 → Map threw an NPE.
   Gen.jl throws `gen_fn_changed_error`.
4. **`product` log-prob broadcasts factors against each other** when their
   value shapes differ (a bernoulli term counted 3 times), and a value with
   too few elements scores only some factors.
5. **Switch resamples addresses shared between branches** on an index
   change. This breaks Def 2.3.1 (unconstrained common addresses keep their
   values) and the regenerate law. It contradicts the "as in Gen.jl"
   docstring, and fails compositionality with the equivalent `if`.
6. **A site constrained with an array of the wrong shape is scored as i.i.d.
   draws**: `(normal 0 1)` constrained to [1 2 3] gave weight −9.757.
7. **Nested constraints under a spliced Distribution are silently ignored**
   in generate and update.
8. **A splice without an address drops the callee's `with-transitions`
   middleware.**
9. **`choice-gradients` always differentiates every float argument**, so
   HMC, MALA and map-optimize crash on models doing host math on a double
   argument. Gen.jl differentiates only arguments annotated `(grad)`.
10. **A body returning an infinite lazy seq hangs** in `realize!`.
11. **Batched Switch with N = 1 throws** on a size-1 index array.
12. **`gen.batched/take` and `select` rebuild without the fallback.**
13. **A spliced Distribution has no batched implementation**, so batched runs
    throw instead of falling back.
14. **`heterogeneous-mixture` casts every draw to the first component's
    dtype**: `[poisson normal]` truncated normal draws to integers.
15. **Missing validation turns bad parameters into NaN or garbage**:
    - `mvnormal` with a non-PD or asymmetric covariance;
    - `dirichlet` with negative alpha;
    - kernel `mix` with negative weights;
    - `piecewise-uniform` with unsorted bounds.
16. **The tape crashes on reductions with `:axis []`**: forward is the
    identity, but backward treats [] as "all axes".

## Likely (unconfirmed): resolved as intended

- **An inner parameter store that shadows a name zeroes the outer store's
  gradient for that name.** This is correct: the outer value is unused there.
  Inner stores override names, as documented in `with-params`.
- **The logsumexp gradient at all −inf inputs is NaN.** The gradient is
  undefined there, and JAX gives NaN too.

## Resolution (2026-10-18)

All 16 are fixed, each with a regression test (bean genclj-k0uy). Bugs 1, 2,
11, 12 and 13 shared a root cause: shape-based batching is ambiguous. The fix
replaced it with a batch tracer (`gen.array.batch`, vmap semantics; spec
`docs/array-api.md` §8b), so batching cannot change meaning by construction.
The fuzzer now generates vector sites and host predicates, and checks batched
updates against the update law particle by particle.

## API and docstring mismatches

- array-api.md §8a says "non-array tests behave exactly as before". But host
  numbers are falsy inside `gen` (numeric truthiness): `(or 0 5)` → 5,
  `(when-let [i 0] …)` skips its body.
- "Batching never changes meaning" was contradicted by bugs 1 and 2.
- The Switch docstring's "as in Gen.jl" (bug 5); `homogeneous-mixture` really
  needs scalar parameters; `with-transitions` (bug 8); `choice-gradients`
  (bug 9); `product` (bug 4).

## Checked and holding

- Unfold update and regenerate (300 random cases: changed parameters, length
  changes, reversal, full vs incremental).
- Batched update and regenerate through Map/Unfold with changed arguments.
- The MH, IS, PF, resampler, HMC, MALA, elliptical-slice and Adam formulas.
- Every other VJP against finite differences.
