# The Generative Function Interface

Part I taught the operations of the generative function interface by
example: `simulate` draws a trace, `generate` conditions it, `update` and
`regenerate` revise it, and their weights are what inference computes
with. This chapter gives the definitions behind them. What is a model, if the
number of its random choices can change from run to run? What exactly is
a weight, a discard, a marginal likelihood? Those questions have precise
answers, and the rest of Part III builds on them.

The chapter follows chapter 2 of Marco Cusumano-Towner's 2020 thesis,
which defines generative functions and traces as abstract data types, and
§4.1 and §4.4 of its chapter 4, which add the internal proposal. It ports
the first chapter of Part III of the GenMLX book. Definitions and
equations carry the thesis's numbers ("Def. 2.1.3", "Eq. 4.1"), and its
notation: $\tau$, $\sigma$, $\rho$ and $\upsilon$ are choice
dictionaries, $A_\tau$ is the set of $\tau$'s addresses, $p$ a
distribution and $q$ a proposal.

Every definition is stated and then checked in gen.clj. Where a model is
small enough to list all of its choice dictionaries, the checks are exact:
the thesis's own examples are such models, and the chapter computes their
tables by hand and compares them with gen.clj, case by case. gen.clj's
laws (`gen.laws`) check the same definitions over random runs of other
models; they appear briefly here, and *Verification: the Laws* explains
them as a test method. Where only sampling reaches, a check holds within
five standard errors.

## Addresses and choice dictionaries

A probabilistic model is classically a joint distribution over a fixed
tuple of random variables. A program does not fit that mold: a loop of
random length, or a branch that makes different choices on different
paths, makes a different number of random choices on different runs. The
thesis starts from names instead of positions. An *address universe*
$(A, V)$ (Def. 2.1.1) is a countable set of addresses $A$ and, for each
address $a$, its domain $V_a$. A *choice dictionary* (Def. 2.1.2) is a
finite map from addresses to values in their domains: $\sigma : A_\sigma
\to \bigcup_a V_a$, with $A_\sigma$ a finite subset of $A$. A random
variable becomes a *random choice*, known by its address.

In gen.clj a choice dictionary is a choice map. An address is any value
but a vector, which is a path of addresses (*Choice Maps, Traces and
Selections*). $\mathcal{T}^\star_B$ is the set of dictionaries whose
addresses lie in $B$. For $A = \{a, b\}$ and $V_a = V_b = \{0, 1\}$ it
holds nine, the thesis's first example: each address is either absent or
takes one of its two values.

<!-- code: dictionaries -->
```clojure
(defn dictionaries
  "Every choice dictionary of an address universe (Def. 2.1.2), given the
   finite domain of each address: Clojure maps in which each address is
   absent or has one of its values."
  [domains]
  (reduce (fn [dicts [a values]]
            (for [dict dicts, v (cons ::absent values)]
              (if (= ::absent v) dict (assoc dict a v))))
          [{}] domains))

(def nine (dictionaries {:a [0 1] :b [0 1]}))

(count nine)
;=> 9

(= (set nine)
   #{{} {:a 0} {:a 1} {:b 0} {:b 1}
     {:a 0 :b 0} {:a 0 :b 1} {:a 1 :b 0} {:a 1 :b 1}})
;=> true
```

Three operations on dictionaries recur below. The *restriction*
$\sigma|_B$ removes the entries outside $B$. Two dictionaries *agree*,
$\sigma \sim \tau$, when they have the same value at every address they
share. The *merge* $\sigma \oplus \tau$ of two dictionaries with no
address in common holds the entries of both. In gen.clj, restriction is
`sel/get-selected` and merge is `cm/merge`:

<!-- code: operations -->
```clojure
(defn restrict
  "σ|_B: the choice map sigma without its choices outside the addresses B."
  [sigma B]
  (sel/get-selected sigma (apply sel/select B)))

(defn agree?
  "σ ~ τ: do the dictionaries sigma and tau (Clojure maps) have the same
   value at every address they share?"
  [sigma tau]
  (every? #(= (sigma %) (tau %)) (filter #(contains? tau %) (keys sigma))))

(def sigma (cm/choicemap :a 0 :b 1))

(cm/to-map (restrict sigma [:a]))
;=> {:a 0}

[(agree? {:a 0 :b 1} {:a 0 :c 1}) (agree? {:a 0 :b 1} {:b 0})]
;=> [true false]

(cm/to-map (cm/merge (cm/choicemap :a 0) (cm/choicemap :b 1)))
;=> {:a 0 :b 1}
```

The thesis defines $\oplus$ only for disjoint dictionaries, and
`cm/merge` makes an overlap a loud error:

<!-- code: merge-error -->
```clojure
;; error: merge: the choice maps overlap
(cm/merge (cm/choicemap :a 0) (cm/choicemap :a 1))
```

From here on the chapter computes with dictionaries as Clojure maps of
host values, which print compactly and serve as keys of tables. `dict`
reads a trace's choices that way, and `cm/from-map` turns a dictionary
back into a choice map for the interface:

<!-- code: dict -->
```clojure
(defn dict
  "The choices of the trace t as a dictionary: a Clojure map of host
   values (for models whose addresses are not nested)."
  [t]
  (update-vals (cm/to-map (:choices t)) array/->clj))
```

## Distributions on choice dictionaries

A *distribution on choice dictionaries* is a map $p :
\mathcal{T}^\star_A \to [0, 1]$ whose values sum to 1 (§2.1.2), and its
*support* $\mathrm{supp}(p)$ is the set of dictionaries with positive
probability. The thesis's running example in §2.3 is a burglary model: a
burglary may happen; a burglar may disable the alarm; an alarm that works
may ring; a neighbor may call. Its universe has four addresses, each
true or false. The thesis's version returns nothing; this one returns
`calls`:

<!-- code: burglary -->
```clojure
(def burglary-model
  (gen []
    (let [burglary (trace :burglary (d/bernoulli 0.01))
          disabled (if burglary (trace :disabled (d/bernoulli 0.1)) false)
          alarm (if disabled
                  false
                  (trace :alarm (d/bernoulli (if burglary 0.94 0.01))))]
      (trace :calls (d/bernoulli (if alarm 0.7 0.05))))))
```

For a dictionary that some run makes, `gfi/assess` returns $\log p(\tau;
x)$. For any other dictionary it refuses, loudly: one that lacks a choice
the run makes, or has a choice it does not. `density` reads a refusal as
probability 0, and `table` lists the probability of every dictionary of a
universe. The burglary universe has $3^4 = 81$ dictionaries, and ten are
in the support, the thesis's "10 possible traces". Their probabilities
sum to 1, and the thesis gives one of them, $p(\{\text{burglary} \mapsto
F, \text{alarm} \mapsto F, \text{calls} \mapsto F\}) = 0.99 \cdot 0.99
\cdot 0.95$:

<!-- code: density -->
```clojure
(defn density
  "p(τ; x): the probability (or density) of the dictionary tau under gf
   on args, by assess. A dictionary that lacks a choice the run makes, or
   has one it does not, is no run's: assess refuses it, and its
   probability is 0."
  [gf args tau]
  (try (array/item (array/exp (:weight (gfi/assess gf args (cm/from-map tau)))))
       (catch clojure.lang.ExceptionInfo e
         (if (some (ex-data e) [:missing-choice :unvisited]) 0.0 (throw e)))))

(defn table
  "The distribution of gf on args over every dictionary of the universe
   with the given domains: a map from dictionary to probability."
  [gf args domains]
  (into {} (map (juxt identity #(density gf args %)))
        (dictionaries domains)))

(defn support
  "The dictionaries of a table with positive probability."
  [table]
  (filter #(pos? (table %)) (keys table)))

(def universe
  (zipmap [:burglary :disabled :alarm :calls] (repeat [true false])))

(def p (table burglary-model [] universe))

[(count p) (count (support p))]
;=> [81 10]

(array/allclose? (reduce + (vals p)) 1.0)
;=> true

(array/allclose? (p {:burglary false :alarm false :calls false})
                 (* 0.99 0.99 0.95))
;=> true
```

The thesis describes the density of a program informally (p. 61): a
dictionary $\tau$ has positive probability when some run of the program,
taking each choice's value from $\tau$, makes exactly $\tau$'s choices,
and then $p(\tau)$ is the product of the probabilities of the choices the
run meets. `factors` writes that run by hand, apart from gen.clj: each
address with its choice's probability given the choices before it. The
product agrees with `assess` on all 81 dictionaries:

<!-- code: factors -->
```clojure
(defn bern
  "The probability of the value v under (d/bernoulli prob)."
  [prob v]
  (if v prob (- 1.0 prob)))

(defn factors
  "The burglary model's run that makes the dictionary tau, by hand: a map
   from each address to the probability of its choice given the choices
   before it, or nil when no run makes tau (a choice missing or extra)."
  [{:keys [burglary disabled alarm calls] :as tau}]
  (let [disabled? (and burglary disabled)
        visits (cond-> #{:burglary :calls}
                 burglary (conj :disabled)
                 (not disabled?) (conj :alarm))]
    (when (= visits (set (keys tau)))
      (cond-> {:burglary (bern 0.01 burglary)
               :calls (bern (if (and (not disabled?) alarm) 0.7 0.05) calls)}
        burglary (assoc :disabled (bern 0.1 disabled))
        (not disabled?) (assoc :alarm (bern (if burglary 0.94 0.01) alarm))))))

(defn by-hand
  "p(τ) by hand: the product of the factors of tau's run, or 0."
  [tau]
  (if-let [fs (factors tau)] (reduce * (vals fs)) 0.0))

(every? #(array/allclose? (p %) (by-hand %)) (keys p))
;=> true
```

The ten runs, as a tree in the order the model makes its choices, most
probable first (b, d, a and c stand for burglary, disabled, alarm and
calls):

<!-- code: runs-figure -->
```clojure

  "The choices of the dictionary tau in the order the model makes them,
   each labeled with its address's initial and its value."
  [tau]
  (for [a [:burglary :disabled :alarm :calls]
        :when (contains? tau a)]
    (symbol (str (first (name a)) "=" (if (tau a) "T" "F")))))

```

![The burglary model's ten runs: each path from the root is one
dictionary of the support, and its shaded end is its last
choice](figures/031-runs.svg)

The runs make different sets of choices: no alarm choice when a burglar
disabled it, no disabled choice without a burglar. No fixed tuple of
random variables describes this distribution, and a dictionary per run
does.

A distribution is *structured* (Def. 2.1.3) when any two dictionaries in
its support are the same or have different values at an address they
share; equivalently, $\tau, \tau' \in \mathrm{supp}(p)$ and $\tau \sim
\tau'$ imply $\tau = \tau'$. The burglary model is structured: two runs
that make different sets of choices part ways at a choice they both made.
The thesis's two counterexamples are not. In the first, the empty
dictionary agrees with both others; in the second, every dictionary
agrees with every other:

<!-- code: structured -->
```clojure
(defn structured?
  "Def. 2.1.3: are any two dictionaries in the support of the table
   either the same or different at an address they share?"
  [table]
  (let [supp (support table)]
    (every? (fn [[s t]] (or (= s t) (not (agree? s t))))
            (for [s supp, t supp] [s t]))))

(def maybe-a {{} 0.5, {:a true} 0.25, {:a false} 0.25})

(def all-ones {{1 1} 0.5, {1 1, 2 1} 0.25, {1 1, 2 1, 3 1} 0.125})

[(structured? p) (structured? maybe-a) (structured? all-ones)]
;=> [true false false]
```

In the first, something not recorded among the choices decided whether to
make the choice at $a$. A `gen` body whose control flow tests only its
arguments and its random choices is structured; Exercise 1 breaks that
rule.

## Marginal likelihood and conditioning

Observations are a dictionary $\rho$. Eq. 2.1 defines two events for it:
$E_\rho = \{\tau : \tau \sim \rho\}$, the dictionaries that agree with
$\rho$ where they share addresses, and $E'_\rho$, those that also hold
all of $\rho$'s addresses. The thesis's example (p. 50) flips a coin at
addresses 1, 2, … until it lands false:

<!-- code: flips -->
```clojure
(def flips
  (gen []
    (loop [i 1]
      (if (trace i (d/bernoulli 0.5))
        (recur (inc i))
        i))))

(def flips-table
  "The flips model's dictionaries of up to 40 flips, with their
   probabilities: {1 F}, {1 T, 2 F}, … (the rest of the support has
   probability 2^-40)."
  (into {} (for [k (range 1 41)
                 :let [tau (assoc (zipmap (range 1 k) (repeat true)) k false)]]
             [tau (density flips [] tau)])))

(flips-table {1 true 2 true 3 false})
;=> 0.125
```

`flips-table` holds its runs of up to 40 flips, the run of $k$ flips
with probability $0.5^k$. For $\rho = \{2 \mapsto T\}$, the thesis's
table of the two events:

<!-- code: events -->
```clojure
(defn in-event?
  "Is tau in the event E_ρ (Eq. 2.1): does it agree with rho?"
  [rho tau]
  (agree? tau rho))

(defn in-event'?
  "Is tau in the event E'_ρ (Eq. 2.1): does it agree with rho and hold
   all of rho's addresses?"
  [rho tau]
  (and (agree? tau rho) (every? #(contains? tau %) (keys rho))))

(def rho {2 true})

(mapv (juxt #(in-event? rho %) #(in-event'? rho %))
      [{1 false} {1 true 2 false} {1 true 2 true 3 false}])
;=> [[true false] [false false] [true true]]
```

The run $\{1 \mapsto F\}$ shares no address with $\rho$, so it agrees with
it, though it never made the second flip: it is in $E_\rho$ and not in
$E'_\rho$. The two events coincide when $\rho$ is *existentially sound*
under $p$ (Def. 2.1.4): when every dictionary in the support holds all of
$\rho$'s addresses. Every run makes the first flip and not every run makes
the second. In the burglary model every run makes the call, and a run
whose alarm was disabled makes no alarm choice:

<!-- code: sound -->
```clojure
(defn sound?
  "Def. 2.1.4: is rho existentially sound under the table: does every
   dictionary in its support hold all of rho's addresses?"
  [table rho]
  (every? (fn [tau] (every? #(contains? tau %) (keys rho))) (support table)))

[(sound? flips-table {1 true}) (sound? flips-table rho)]
;=> [true false]

[(sound? p {:calls true}) (sound? p {:alarm true})]
;=> [true false]
```

The *marginal likelihood* of a dictionary $\sigma$ (Def. 2.1.5) is the
probability of $E_\sigma$:

$$
\bar p(\sigma) = \sum_{\tau \in \mathcal{T}^\star_A} p(\tau)\,[\tau \sim \sigma].
\tag{2.2}
$$

For the flips and $\sigma = \{2 \mapsto T\}$, the thesis's value (p. 51)
is $0.5 + \sum_{i \ge 3} 0.5^i = 0.75$, the first term the run $\{1
\mapsto F\}$:

<!-- code: marginal -->
```clojure
(defn marginal
  "p̄(σ), Eq. 2.2: the total probability of the table's dictionaries that
   agree with sigma."
  [table sigma]
  (reduce + 0.0 (map table (filter #(agree? % sigma) (keys table)))))

(array/allclose? (marginal flips-table rho) 0.75)
;=> true
```

The *conditional distribution* (Def. 2.1.6) is a distribution on the
dictionaries $\upsilon$ of the other addresses:

$$
p(\upsilon \mid \sigma) = \sum_{B \subseteq A_\sigma}
\frac{p(\upsilon \oplus \sigma|_B)}{\bar p(\sigma)}.
\tag{2.4}
$$

The thesis's table for the flips gives two thirds of the conditional
probability to the run that stopped at the first flip, which never made
the observed choice; $\{1 \mapsto T\}$ gets none, since no run makes
exactly that dictionary, with or without $2 \mapsto T$:

<!-- code: conditional -->
```clojure
(defn subsets
  "Every subset of the collection xs, as sets."
  [xs]
  (reduce (fn [ss x] (concat ss (map #(conj % x) ss))) [#{}] xs))

(defn conditional
  "p(υ | σ), Eq. 2.4: the probability of the dictionary v (on addresses
   outside sigma's) given sigma: the total over the subsets B of sigma's
   addresses of the probability of v merged with σ|_B, over p̄(σ)."
  [table sigma v]
  (/ (reduce + 0.0 (for [B (subsets (keys sigma))]
                     (table (merge v (select-keys sigma B)) 0.0)))
     (marginal table sigma)))

(mapv #(conditional flips-table rho %)
      [{1 false} {1 true} {1 true 3 false} {1 true 3 true 4 false}])
;=> [0.6667 0.0 0.16667 0.08333]
```

When $p$ is structured and $\sigma$ existentially sound, only $B =
A_\sigma$ contributes, and the sums simplify to

$$
\bar p(\sigma) = \sum_{\upsilon} p(\upsilon \oplus \sigma) \quad (2.3),
\qquad p(\upsilon \mid \sigma) = \frac{p(\upsilon \oplus \sigma)}{\bar
p(\sigma)} \quad (2.5).
$$

`marginal-sound` sums Eq. 2.3 over every dictionary $\upsilon$ of the
other addresses. For calls = true, existentially sound, it agrees with
Eq. 2.2: a neighbor calls with probability 0.06193. For alarm = true it
falls short. Eq. 2.3 misses the runs that never consult the alarm yet
agree with $\sigma$, those with a disabled alarm, whose probability is
$0.01 \cdot 0.1$:

<!-- code: marginal-sound -->
```clojure
(defn marginal-sound
  "p̄(σ) by Eq. 2.3, for a structured table and an existentially sound
   sigma: the total probability of sigma merged with each dictionary of
   the other addresses."
  [table domains sigma]
  (reduce + 0.0 (for [v (dictionaries (apply dissoc domains (keys sigma)))]
                  (table (merge v sigma) 0.0))))

(def calls {:calls true})

(marginal p calls)
;=> 0.06193

(array/allclose? (marginal p calls) (marginal-sound p universe calls))
;=> true

[(marginal p {:alarm true}) (marginal-sound p universe {:alarm true})]
;=> [0.01936 0.01836]

(array/allclose? (- (marginal p {:alarm true})
                    (marginal-sound p universe {:alarm true}))
                 (* 0.01 0.1))
;=> true
```

Eq. 2.5 gives the posterior given a call, a table over the dictionaries
of the other three addresses. It sums to 1, and it is structured, as
Prop. 2.1.2 says the conditional of a structured distribution is. A call
raises the probability of a burglary from 0.01 to 0.09686:

<!-- code: posterior -->
```clojure
(def posterior
  "p(· | calls = true), Eq. 2.5: the burglary model's dictionaries without
   :calls, each with its conditional probability."
  (into {} (for [v (dictionaries (dissoc universe :calls))]
             [v (/ (p (merge v calls)) (marginal p calls))])))

[(array/allclose? (reduce + (vals posterior)) 1.0) (structured? posterior)]
;=> [true true]

(def burglary-given-calls
  (reduce + (map posterior (filter :burglary (keys posterior)))))

burglary-given-calls
;=> 0.09686
```

Conditioning on $\sigma$ is restriction to the event $E_\sigma$, so
sampling can check it. Over 50000 runs, the fraction that call estimates
$\bar p(\{\text{calls} \mapsto T\})$, the expectation of the indicator
$[\tau \sim \sigma]$ (Def. 2.1.8); among those runs, the fraction with a
burglary estimates the posterior probability. Both agree with the exact
values within five standard errors. This is rejection sampling
(*Conditioning*):

<!-- code: rejection -->
```clojure
(def runs
  "50000 runs of the burglary model, as dictionaries."
  (mapv #(dict (gfi/simulate burglary-model [] %))
        (rng/split (rng/key 1) 50000)))

(defn within-5-se?
  "Is the frequency of hits among n trials within five standard errors of
   the probability prob?"
  [hits n prob]
  (< (abs (- (/ hits (double n)) prob))
     (* 5 (Math/sqrt (/ (* prob (- 1.0 prob)) n)))))

(within-5-se? (count (filter :calls runs)) (count runs) (marginal p calls))
;=> true

(let [kept (filter :calls runs)]
  (within-5-se? (count (filter :burglary kept)) (count kept)
                burglary-given-calls))
;=> true
```

As *Conditioning* showed, `generate`'s weight estimates the marginal
likelihood too: the exponential of the weight has expectation $\bar
p(\sigma)$, which the section on the internal proposal derives. 5000 runs
agree with the exact value:

<!-- code: estimate -->
```clojure
(defn estimate
  "The average of exp(weight) over n runs of generate on gf, args and the
   constraints (a Clojure map), one key each, and its standard error."
  [gf args constraints n key]
  (let [sigma (cm/from-map constraints)
        weight #(:weight (gfi/generate gf args sigma %))
        ws (mapv #(array/item (array/exp (weight %))) (rng/split key n))
        mean (/ (reduce + ws) n)
        var (/ (reduce + (map #(* (- % mean) (- % mean)) ws)) (dec n))]
    {:mean mean :se (Math/sqrt (/ var n))}))

(let [{:keys [mean se]} (estimate burglary-model [] calls 5000 (rng/key 2))]
  (< (abs (- mean (marginal p calls))) (* 5 se)))
;=> true
```

The thesis conditions on $E_\sigma$, which gives observations that are
not existentially sound a meaning, and then assumes that observed data
are existentially sound. gen.clj checks the assumption run by run: a run
that does not make a constrained choice is a loud error. With the
constraint $\{2 \mapsto T\}$, half of all runs of the flips stop before
the second flip, so among twenty runs one almost surely does:

<!-- code: generate-strict -->
```clojure
;; error: generate: the constraint at [2] was not visited
(mapv #(gfi/generate flips [] (cm/choicemap 2 true) %)
        (rng/split (rng/key 28) 20))
```

So `generate`'s weights estimate $\bar p(\sigma)$ for existentially sound
observations, and gen.clj refuses the others rather than condition on
$E_\sigma$.

A conditional distribution needs $\bar p(\sigma) > 0$. A distribution is
*supportive* (Def. 2.1.7) when every dictionary of the universe has
positive marginal likelihood, so that every conditional is defined. The
burglary model is supportive. The thesis's counterexample is a coin that
always lands true, in a universe where it could land false. `generate`
constrained to the impossible value returns the weight $-\infty$:

<!-- code: supportive -->
```clojure
(every? #(pos? (marginal p %)) (keys p))
;=> true

(def certain
  (gen []
    (trace :a (d/bernoulli 1.0))))

(marginal (table certain [] {:a [true false]}) {:a false})
;=> 0.0

(:weight (gfi/generate certain [] (cm/choicemap :a false) (rng/key 3)))
;=> ##-Inf
```

`regenerate` conditions on whatever choices it keeps, so the thesis
defines it only for supportive distributions.

## Densities

Continuous choices need densities, and densities need a reference measure
(Defs. 2.1.9 and 2.1.10). Each address has a measure on its domain:
counting measure on a discrete one, Lebesgue measure on the reals. The
dictionaries with one set of addresses get the product measure, and
$\mathcal{T}^\star_A$ the sum over the sets of addresses. A density $p$
on choice dictionaries is then the density of a probability measure with
respect to that reference measure. The thesis's example (pp. 53–54) draws
a geometric number $n \ge 1$ of standard normals, at addresses $(x, i)$,
and a normal $y$ around their sum. gen.clj's geometric counts failures
from 0, as Gen.jl's does, so the model adds one. Its loop tests with
`array/<`, gen.array's comparison, so that a backend whose values are
arrays (MLX) runs it too. A dictionary's density is a product of one
probability and normal densities:

<!-- code: sum-model -->
```clojure
(def sum-model
  (gen []
    (let [n (+ 1 (trace :n (d/geometric 0.5)))
          xs (loop [i 0, xs []]
               (if (array/< i n)
                 (recur (inc i) (conj xs (trace [:x i] (d/normal 0 1))))
                 xs))]
      (trace :y (d/normal (reduce + xs) 1)))))

(defn normal-density
  "The density of (d/normal mu sd) at x, by hand."
  [x mu sd]
  (/ (Math/exp (* -0.5 (Math/pow (/ (- x mu) sd) 2)))
     (* sd (Math/sqrt (* 2 Math/PI)))))

(array/allclose? (density sum-model [] {:n 1 :x {0 0.3 1 -0.2} :y 0.5})
                 (* 0.25 (normal-density 0.3 0 1) (normal-density -0.2 0 1)
                    (normal-density 0.5 0.1 1)))
;=> true
```

The marginal likelihood of a continuous observation integrates the other
choices out (Def. 2.1.12):

$$
\bar p(\sigma) = \int p(\upsilon \oplus \sigma)\, \mu^\star_{A \setminus
A_\sigma}(d\upsilon). \tag{2.7}
$$

Given $n$, the observation $y$ is the sum of $n + 1$ standard normals, so
$\bar p(\{y \mapsto 1.5\}) = \sum_{n \ge 1} 0.5^n\, \mathcal{N}(1.5; 0,
\sqrt{n + 1})$. The thesis gives 0.15573434:

<!-- code: sum-marginal -->
```clojure
(defn sum-marginal
  "The marginal likelihood of the observation y under sum-model, by the
   thesis's series: given n normals, y is normal with mean 0 and variance
   n + 1, and n has probability 0.5^n."
  [y]
  (reduce + (for [n (range 1 200)]
              (* (Math/pow 0.5 n) (normal-density y 0 (Math/sqrt (inc n)))))))

(sum-marginal 1.5)
;=> 0.15573434
```

`generate`'s weights estimate it. At the thesis's $y = 1.5$, though, the

depends on it, and the estimates agree with the series within five
standard errors at both:

## The generative function as a tuple

A *generative function* (Def. 2.1.16) is a tuple $\mathcal{P} = (X, Y,
p, f)$: an argument type $X$; a return type $Y$; for each argument $x$, a
structured, well-behaved density $p(\cdot\,; x)$ on choice dictionaries;
and a return-value function $f(x, \tau)$ defined on the support. The
arguments and the return value are what make generative functions
compose. The thesis's three examples: a deterministic function, $x
\mapsto 2x$, whose only dictionary is the empty one, with probability 1;
a distribution that depends on the argument; and a function that makes a
choice for one argument and none for the other:

<!-- code: tuple-examples -->
```clojure
(def twice (gen [x] (* 2 x)))

(let [t (gfi/simulate twice [3.0] (rng/key 6))]
  [(cm/empty? (:choices t)) (:score t) (:retval t)])
;=> [true 0.0 6.0]

(def depends
  (gen [x]
    (if (trace :a (d/bernoulli x)) x 0.0)))

(defn row
  "A dictionary's probability under gf on args, and its return value."
  [gf args tau]
  [(density gf args tau) (:retval (gfi/assess gf args (cm/from-map tau)))])

[(row depends [0.3] {:a true}) (row depends [0.3] {:a false})]
;=> [[0.3 0.3] [0.7 0.0]]

(def choosy
  (gen [x]
    (when x (trace :n (d/geometric 0.5)))
    0))

[(row choosy [false] {}) (mapv #(row choosy [true] {:n %}) [0 1 2])]
;=> [[1.0 0] [[0.5 0] [0.25 0] [0.125 0]]]
```

A *trace* is a tuple $\mathbf{t} = (\mathcal{P}, x, \tau)$ (§2.3.1).
gen.clj's trace holds the three as `:gen-fn`, `:args` and `:choices`, and
keeps two values derived from them: $f(x, \tau)$ as `:retval` and $\log
p(\tau; x)$ as `:score`:

<!-- code: trace-tuple -->
```clojure
(def t (gfi/simulate burglary-model [] (rng/key 7)))

[(dict t) (:retval t)]
;=> [{:burglary false :alarm false :calls false} false] ; float64

(array/allclose? (:score t) (Math/log (p (dict t))))
;=> true
```

The derived fields must be what $\mathcal{P}$ says they are, and that is
the first of gen.clj's laws. A law is a property a generative function
must have, checked over random runs. `law` checks one in 50
cases drawn from four models: the burglary model, the flips, the sum, and
`depends`, which a case also runs on another argument. `laws/check`
fails a law most of whose cases say nothing (a case is vacuous when, for
example, constraints from one run cannot be visited by another). Each
law below confirms a definition over more runs than a table lists:

<!-- code: law -->
```clojure
(def law-models
  [["burglary" burglary-model [] []]
   ["flips" flips [] []]
   ["sum" sum-model [] []]
   ["depends" depends [0.3] [[0.8]]]])

(defn law
  "Checks a law of gen.laws over the models in n cases (from one seed):
   whether it passed. laws/check fails a law most of whose cases were
   vacuous."
  [law-fn models n]
  (-> (laws/check n (law-fn (laws/cases models)) {:seed 31})
      (select-keys [:pass? :num-tests])))

(law laws/score-is-the-assessed-density law-models 50)
;=> {:pass? true :num-tests 50}
```

## The operations

§2.3 makes generative functions and traces abstract data types: objects
known only through operations whose meaning comes from $(X, Y, p, f)$.
The thesis's chapter 2 defines simulate, generate, logpdf, choices,
update and gradients. Gen.jl adds assess, propose and project, and the
thesis's chapter 4 adds the generate of a partial dictionary and
regenerate, which need the internal proposal of the next section.

### Simulate

`simulate` samples $\tau \sim p(\cdot\,; x)$ and returns the trace
$(\mathcal{P}, x, \tau)$. For the burglary model it returns each of the
ten traces with its probability. Every one of the 50000 runs above is in
the support, and each dictionary's frequency is within five standard
errors of its probability:

<!-- code: simulate -->
```clojure
(defn frequencies-agree?
  "Is the frequency of each dictionary of the table's support among the
   runs within five standard errors of its probability?"
  [table runs]
  (let [n (count runs)
        counts (frequencies runs)]
    (every? #(within-5-se? (counts % 0) n (table %)) (support table))))

[(every? #(pos? (p %)) runs) (frequencies-agree? p runs)]
;=> [true true]
```

The thesis's logpdf and choices are a trace's `:score` and `:choices`, as
above.

### Generate with every choice

The thesis's §2.3 version of `generate` takes a dictionary $\sigma$ that
determines a run, and builds the trace of $\tau = \sigma|_B$ without
sampling. In the thesis's example the trace holds the given choices, and
its log probability is $\log(0.99 \cdot 0.99 \cdot 0.95)$. With every
choice given, the weight is the score, which a law checks:

<!-- code: generate-complete -->
```clojure
(def quiet {:burglary false :alarm false :calls false})

(let [{t :trace w :weight}
      (gfi/generate burglary-model [] (cm/from-map quiet) (rng/key 8))]
  [(= quiet (dict t)) (array/allclose? w (:score t))
   (array/allclose? (:score t) (Math/log (* 0.99 0.99 0.95)))])
;=> [true true true]

(law laws/generate-with-every-choice-is-deterministic law-models 50)
;=> {:pass? true :num-tests 50}
```

The thesis lets $\sigma$ hold entries the run does not make: an extra
$\text{foo} \mapsto F$ "results in the same output". gen.clj refuses it,
since an unvisited constraint is more often a misspelled address than a
deliberate one:

<!-- code: generate-extra -->
```clojure
;; error: generate: the constraint at [:foo] was not visited
(gfi/generate burglary-model [] (cm/from-map (assoc quiet :foo false))
                (rng/key 8))
```

### Assess and propose

Two operations of Gen.jl's are not in the thesis's chapter 2. `assess`

$\tau$ and returns it with $\log p(\tau; x)$: `simulate` seen as a
proposal distribution, which *Inference as Operations on the GFI* puts to
work. Their laws: propose's weight is the assessed density, and assess's
weight is generate's, on every choice:

<!-- code: assess-propose -->
```clojure

  (array/allclose? w (Math/log (p (update-vals (cm/to-map c) array/->clj)))))
;=> true

[(law laws/propose-weight-is-the-assessed-density law-models 50)
```

### Update

`update` changes some choices of a trace and keeps the rest. Def. 2.3.1
says which: given $\tau$ in the support and a change $\sigma$,
$h_{\mathrm{update}}(\tau, \sigma) = (\tau', \sigma')$, where $\tau' =
(\tau|_B) \oplus \sigma$ is in the support for some $B$ (unique, by
Prop. 2.1.3) and $\sigma' = \tau|_C$ for $C = A_{\tau'}^{\mathsf{c}} \cup
A_\sigma$: the old values at the addresses $\sigma$ sets and at those
$\tau'$ lacks. When no $B$ makes a $\tau'$ in the support, the result is
$\bot$. `h-update` searches the subsets $B$ by hand. Disabling the alarm
on a run where a burglar left it working drops the alarm choice, and
$\sigma'$ holds the old disabled and the dropped alarm. A burglary on a
run without one is $\bot$: the new run needs a disabled choice, which
neither $\tau$ nor $\sigma$ gives. Over every $\tau$ and $\sigma$, at most
one $B$ makes a $\tau'$ in the support, as Prop. 2.1.3 says:

<!-- code: h-update -->
```clojure
(defn h-update
  "Def. 2.3.1: [τ' σ'] for the dictionary tau and the change sigma under
   the table, where τ', τ|_B merged with sigma, is in the support for
   some B, and σ' is tau at the addresses τ' lacks or sigma sets; nil
   (the thesis's bottom) when no B gives one."
  [table tau sigma]
  (some (fn [B]
          (let [tau' (merge (select-keys tau B) sigma)]
            (when (pos? (table tau' 0.0))
              [tau' (select-keys tau (filter #(or (contains? sigma %)
                                                  (not (contains? tau' %)))
                                             (keys tau)))])))
        (subsets (remove #(contains? sigma %) (keys tau)))))

(def alarmed {:burglary true :disabled false :alarm true :calls true})

(h-update p alarmed {:disabled true})
;=> [{:burglary true :disabled true :calls true} {:disabled false :alarm true}]

(h-update p {:burglary false :alarm true :calls true} {:burglary true})
;=> nil

(every? (fn [[tau sigma]]
          (>= 1 (count (distinct
                        (for [B (subsets (remove #(contains? sigma %)
                                                 (keys tau)))
                              :let [tau' (merge (select-keys tau B) sigma)]
                              :when (pos? (p tau' 0.0))]
                          tau')))))
        (for [tau (support p), sigma (keys p)] [tau sigma]))
;=> true
```

The update operation returns the new trace, $\sigma'$ (the *discard*),
the weight

$$
\log w = \log \frac{p(\tau'; x')}{p(\tau; x)},
$$

and a change hint for the return value. Of the 810 pairs of a trace of
the support and a change, 384 have a $\tau'$. On each, gen.clj's
`update` makes Def. 2.3.1's $\tau'$, returns its $\sigma'$ as the
discard, and returns that weight:

<!-- code: update-exhaustive -->
```clojure
(defn trace-of
  "The trace of gf on args whose choices are the dictionary tau."
  [gf args tau]
  (:trace (gfi/generate gf args (cm/from-map tau) (rng/key 0))))

(defn updated
  "gfi/update of the burglary model's trace of tau with the change sigma:
   the new dictionary, the discard (a dictionary) and the weight."
  [tau sigma]
  (let [{t :trace w :weight disc :discard}
        (gfi/update (trace-of burglary-model [] tau) (cm/from-map sigma)
                    (rng/key 10))]
    [(dict t) (update-vals (cm/to-map disc) array/->clj) w]))

(def update-cases
  (for [tau (support p), sigma (keys p)
        :let [h (h-update p tau sigma)]
        :when h]
    [tau sigma h]))

(count update-cases)
;=> 384

(every? (fn [[tau sigma [tau' sigma']]]
          (let [[new discard w] (updated tau sigma)]
            (and (= tau' new) (= sigma' discard)
                 (array/allclose? w (Math/log (/ (p tau') (p tau)))))))
        update-cases)
;=> true
```

Prop. 2.3.1: $h_{\mathrm{update}}(\tau', \sigma') = (\tau, \sigma)$, so
the discard undoes the update. It holds by hand and in gen.clj, on every
case (`pop` drops the weight), and the law checks it over random runs:

<!-- code: reversible -->
```clojure
(every? (fn [[tau sigma [tau' sigma']]]
          (and (= [tau sigma] (h-update p tau' sigma'))
               (= [tau sigma] (pop (updated tau' sigma')))))
        update-cases)
;=> true

(law laws/updates-are-reversible-with-exact-discards law-models 50)
;=> {:pass? true :num-tests 50}
```

For the other 426 pairs Def. 2.3.1 says nothing. gen.clj throws when
$\sigma$ sets an address the new run does not visit. Otherwise it does
what Gen.jl does: it draws the choices the new run needs and $\sigma$
does not give, and their density stays out of the weight (*Update and
Regenerate*). Which of the two happens can depend on what it draws: a
freshly drawn disabled choice that comes up true takes the alarm choice
away.

<!-- code: update-bottom -->
```clojure
(defn update-outcome
  "What gfi/update does with a change that Def. 2.3.1 leaves undefined:
   :draws-fresh choices, or throws on an :unvisited constraint."
  [tau sigma]
  (try (updated tau sigma) :draws-fresh
       (catch clojure.lang.ExceptionInfo e
         (if (:unvisited (ex-data e)) :unvisited (throw e)))))

(frequencies (for [tau (support p), sigma (keys p)
                   :when (nil? (h-update p tau sigma))]
               (update-outcome tau sigma)))
;=> {:unvisited 372 :draws-fresh 54} ; float64
```

The arguments may change too, and a *change hint* (Def. 2.3.2) says how:
$\top$ that an argument did not change, $\bot$ nothing at all, and a hint
between them part of the change. gen.clj's argdiffs are `diff/no-change`,
`diff/unknown-change` and finer hints such as `diff/vector-diff`. The
thesis's example appends a draw to its argument, a vector. Negating the
second element, with a hint that only element 1 changed (Julia's element
2) and no new choices, keeps the draw, with weight 0 and an empty
discard. The returned hint must describe the change of the return value:
gen.clj's dynamic functions return $\bot$, always valid, and the finer
hint that the thesis also lists would be valid too:

<!-- code: change-hints -->
```clojure
(def append
  (gen [xs]
    (conj xs (trace :a (d/normal 0 1)))))

(def appended (gfi/simulate append [[4.2 5.3 3.3 1.1]] (rng/key 11)))

(def negated
  (gfi/update appended [[4.2 -5.3 3.3 1.1]]
              [(diff/vector-diff 4 4 {1 diff/unknown-change})]
              cm/EMPTY (rng/key 12)))

[(:weight negated) (cm/empty? (:discard negated))
 (= (appended :a) ((:trace negated) :a))]
;=> [0.0 true true]

[(diff/unknown-change? (:retdiff negated))
 (diff/consistent? (:retval appended) (:retval (:trace negated))
                   (diff/vector-diff 5 5 {1 diff/unknown-change}))]
;=> [true true]
```

### Gradients

The last trace operation computes gradients. For a function $\ell$ of the
return value, let $g(x, \tau) = \log p(\tau; x) + \ell(f(x, \tau))$ (Eq.
2.10) and $v = \nabla \ell$ at $f(x, \tau)$. The gradient operation
returns $\nabla_x g = \nabla_x \log p(\tau; x) + J(x, \tau)\,v$ (Eq.
2.11), with $J$ the Jacobian of $f$ in $x$, and for each selected
continuous choice

$$
\frac{\partial g}{\partial \tau[a]} = \frac{\partial \log p(\tau;
x)}{\partial \tau[a]} + \sum_i \frac{\partial f(x, \tau)_i}{\partial
\tau[a]}\, v_i. \tag{2.12}
$$

`grad/choice-gradients` takes $v$ as its third argument and the
arguments to differentiate as `:argnums`. On a model that draws $\mu \sim
\mathcal{N}(x, 1)$ and $y \sim \mathcal{N}(\mu, 0.5)$ and returns
$\mu^2$, with $x = 1$, $\mu = 0.4$, $y = 1.2$ and $v = 2$, the two
gradients are the closed forms $(x - \mu) + (y - \mu)/0.25 + 2 \mu v$ and
$\mu - x$:

<!-- code: gradients -->
```clojure
(def sensor
  (gen [x]
    (let [mu (trace :mu (d/normal x 1))]
      (trace :y (d/normal mu 0.5))
      (* mu mu))))

(def sensed
  (trace-of sensor [1.0] {:mu 0.4 :y 1.2}))

(def gradients
  (grad/choice-gradients sensed (sel/select :mu) 2.0 {:argnums [0]}))

(let [[x mu y v] [1.0 0.4 1.2 2.0]]
  [(array/allclose? (cm/get-choice (:gradients gradients) :mu)
                    (+ (- x mu) (/ (- y mu) 0.25) (* 2 mu v)))
   (array/allclose? (first (:arg-grads gradients)) (- mu x))])
;=> [true true]
```

## The internal proposal

`generate` with a partial dictionary, and `regenerate`, must sample the
choices they are not given. Chapter 4 of the thesis adds the sampler to
the tuple. A generative function *with an internal proposal* (Def. 4.1.1)
is $\mathcal{P} = (X, Y, p, f, q)$, where for each $x$ and each $\sigma$
with $\bar p(\sigma; x) > 0$, $q(\cdot\,; x, \sigma)$ is a density on the
dictionaries of the addresses outside $\sigma$, and $q(\upsilon; x,
\sigma) > 0$ exactly when $p(\upsilon \mid \sigma; x) > 0$.

Every `gen` function's internal proposal is *forward sampling* (p. 145):
it runs the body, takes each constrained choice from $\sigma$ and draws
each other choice from its distribution. So $q(\upsilon; x, \sigma)$ is
the product of the probabilities of the drawn choices given the choices
before them. `q-forward` computes it from the hand-written `factors`.
Nine dictionaries are existentially sound under the burglary model, those
over burglary and calls alone, the two choices every run makes; for each,
$q$ sums to 1 over the runs it can complete:

<!-- code: q-forward -->
```clojure
(defn q-forward
  "q(υ; x, σ) of forward sampling (thesis p. 145) for the burglary model:
   the product of the factors of tau's run at υ's addresses, where tau,
   the dictionary the run makes, is υ merged with σ|_B."
  [tau v-addresses]
  (reduce * 1.0 (map (factors tau) v-addresses)))

(defn completions
  "The dictionaries of the burglary model's support that hold sigma: the
   runs that forward sampling may make from sigma."
  [sigma]
  (filter #(in-event'? sigma %) (support p)))

(def sound-sigmas (filter #(sound? p %) (keys p)))

(count sound-sigmas)
;=> 9

(every? (fn [sigma]
          (array/allclose?
           1.0
           (reduce + (map #(q-forward % (remove (set (keys sigma)) (keys %)))
                          (completions sigma)))))
        sound-sigmas)
;=> true
```

The extended `generate` (§4.1.1) draws $\upsilon \sim q(\cdot\,; x,
\sigma)$, makes $\tau = \upsilon \oplus \sigma|_B$, and returns the
weight

$$
\log w = \log \frac{p(\tau; x)}{q(\upsilon; x, \sigma)}.
$$

With forward sampling the drawn choices' factors cancel, and what remains
is the log probability of the constrained choices given the others.
Exactly that weight, on all nine sound dictionaries and five keys each:

<!-- code: generate-weight -->
```clojure
(every? (fn [[sigma k]]
          (let [{t :trace w :weight}
                (gfi/generate burglary-model [] (cm/from-map sigma) k)
                tau (dict t)]
            (array/allclose?
             w (- (Math/log (p tau))
                  (Math/log (q-forward tau (remove (set (keys sigma))
                                                   (keys tau))))))))
        (for [sigma sound-sigmas, k (rng/split (rng/key 13) 5)] [sigma k]))
;=> true
```

The expectation of $w$ under $q$ is $\sum_\upsilon q(\upsilon)\, p(\tau)
/ q(\upsilon) = \sum_\upsilon p(\upsilon \oplus \sigma)$, which is Eq.
2.3's $\bar p(\sigma)$: why the weights estimated the marginal likelihood
above.

Gen.jl defines `project(t, S)` by the internal proposal too: it is
`generate`'s weight for producing $\mathbf{t}$ from the constraints
$\tau|_S$. With forward sampling it is the sum of the log probabilities
of the selected choices, which holds on every trace and every one of the
16 selections, and for any internal proposal it is generate's weight,
which a law checks:

<!-- code: project -->
```clojure
(every? (fn [[tau S]]
          (array/allclose?
           (gfi/project (trace-of burglary-model [] tau) (apply sel/select S))
           (reduce + 0.0 (map #(Math/log ((factors tau) % 1.0)) S))))
        (for [tau (support p), S (subsets (keys universe))] [tau S]))
;=> true

(law laws/generate-weight-is-the-projection law-models 50)
;=> {:pass? true :num-tests 50}
```

`regenerate` (§4.1.2) draws new values for a selection $S$ of addresses.
Let $\sigma = \tau|_{S^{\mathsf{c}}}$, the choices it keeps. It draws
$\upsilon \sim q(\cdot\,; x', \sigma)$ and makes $\tau' = \upsilon \oplus
\sigma|_B$. For the move back, let $\sigma' =
\tau'|_{S^{\mathsf{c}}}$ and $\upsilon' = \tau|_{((A_\tau \cap
A_{\tau'}) \setminus S)^{\mathsf{c}}}$: the choices the reverse move must
draw to return to $\tau$. The weight is

$$
\log w = \log \frac{p(\tau'; x')\, q(\upsilon'; x, \sigma')}{p(\tau;
x)\, q(\upsilon; x', \sigma)}. \tag{4.1}
$$

`eq-4-1` transcribes it with the hand-written $q$. It holds on every
trace, every selection and three keys each, 480 moves:

<!-- code: eq-4-1 -->
```clojure
(defn eq-4-1
  "Regenerate's weight by Eq. 4.1 for the burglary model's forward
   sampling: the move from the dictionary tau to tau' with the selection
   of the addresses S."
  [tau tau' S]
  (let [sigma (apply dissoc tau S)
        sigma' (apply dissoc tau' S)
        v (remove #(contains? sigma %) (keys tau'))
        v' (remove #(contains? sigma' %) (keys tau))]
    (- (+ (Math/log (p tau')) (Math/log (q-forward tau v')))
       (+ (Math/log (p tau)) (Math/log (q-forward tau' v))))))

(def regenerate-cases
  (for [tau (support p), S (subsets (keys universe)),
        k (rng/split (rng/key 14) 3)]
    [tau S k]))

(count regenerate-cases)
;=> 480

(every? (fn [[tau S k]]
          (let [{t' :trace w :weight}
                (gfi/regenerate (trace-of burglary-model [] tau)
                                (apply sel/select S) k)]
            (array/allclose? w (eq-4-1 tau (dict t') S))))
        regenerate-cases)
;=> true

(law laws/regenerate-weight-is-the-retained-density-ratio law-models 50)
;=> {:pass? true :num-tests 50}
```

*Update and Regenerate* simplified Eq. 4.1 for forward sampling to the
ratio of the densities of the retained choices, and the law above checks
that form; here the equation is checked as the thesis states it.

### Another internal proposal

Nothing in Def. 4.1.1 asks for forward sampling. The thesis's example
(p. 143) gives a distribution on dictionaries of $a$, $b$ and $c$ by a
table, and a proposal $q$ by tables for two constraints. As a `gen`
model, its table is the thesis's:

<!-- code: abc -->
```clojure
(def abc
  (gen []
    (let [a (trace :a (d/bernoulli 0.5))
          b (when a (trace :b (d/bernoulli 0.5)))]
      (trace :c (d/bernoulli (cond (not a) 0.1 b 0.5 :else 0.8))))))

(mapv #(density abc [] %)
      [{:a false :c false} {:a false :c true} {:a true :b false :c false}
       {:a true :b false :c true} {:a true :b true :c false}
       {:a true :b true :c true}])
;=> [0.45 0.05 0.05 0.2 0.125 0.125]
```

`prop/with-internal-proposal` is the thesis's combinator for overriding
the internal proposal (§4.4, Alg. 16): the same distribution and traces,
another $q$. The proposal is a generative function of the constraints,
and it makes choices only where they leave an opening; forward sampling
makes the rest. `abc-q` draws $a$ true with probability 0.6, then $b$ and
$c$ with 0.5 each. Given $\sigma_1 = \{c \mapsto T\}$ it is the thesis's
$q(\cdot\,; \sigma_1)$: $\{a \mapsto F\}$ with 0.4, $\{a \mapsto T, b
\mapsto F\}$ and $\{a \mapsto T, b \mapsto T\}$ with 0.3 each:

<!-- code: abc-q -->
```clojure
(defn given?
  "Do the constraints give a value at addr?"
  [constraints addr]
  (cm/has-value? constraints addr))

(def abc-q
  (gen [constraints]
    (let [a (if (given? constraints :a)
              (cm/get-choice constraints :a)
              (trace :a (d/bernoulli 0.6)))]
      (when (and a (not (given? constraints :b)))
        (trace :b (d/bernoulli 0.5)))
      (when-not (given? constraints :c)
        (trace :c (d/bernoulli 0.5))))))

(def abc* (prop/with-internal-proposal abc abc-q))
```

The thesis's run draws $\upsilon = \{a \mapsto F\}$ and makes $\tau =
\{a \mapsto F, c \mapsto T\}$, with $\log w = \log 0.05 - \log 0.4$:

<!-- code: abc-generate -->
```clojure
(def a-false
  (first (filter #(false? ((:trace %) :a))
                 (map #(gfi/generate abc* [] (cm/choicemap :c true) %)
                      (rng/split (rng/key 15) 30)))))

[(dict (:trace a-false)) (:weight a-false)]
;=> [{:a false :c true} -2.0794]

(array/allclose? (:weight a-false) (Math/log (/ 0.05 0.4)))
;=> true
```

Its regenerate (p. 144) starts from $\tau = \{a \mapsto T, b \mapsto F, c
\mapsto T\}$ with $S = \{a, b\}$, so $\sigma = \{c \mapsto T\}$. Drawing
$\upsilon = \{a \mapsto F\}$ makes $\tau' = \{a \mapsto F, c \mapsto
T\}$; the reverse move must draw $\upsilon' = \{a \mapsto T, b \mapsto
F\}$, with $q$ 0.3; and $\log w = \log (0.05 \cdot 0.3)/(0.2 \cdot 0.4)$:

<!-- code: abc-regenerate -->
```clojure

(def to-a-false
  (first (filter #(false? ((:trace %) :a))
                 (map #(gfi/regenerate abc-t (sel/select :a :b) %)
                      (rng/split (rng/key 16) 30)))))

[(dict (:trace to-a-false)) (:weight to-a-false)]
;=> [{:a false :c true} -1.674]

(array/allclose? (:weight to-a-false)
                 (Math/log (/ (* 0.05 0.3) (* 0.2 0.4))))
;=> true
```

`project` follows the internal proposal. Selecting $c$ on $\{a \mapsto
F, c \mapsto T\}$, the override's projection is generate's weight from
$\{c \mapsto T\}$, $\log 0.05 - \log 0.4$. The model's own projection is
forward sampling's, the log probability of $c$ given $a$, $\log 0.1$:

<!-- code: abc-project -->
```clojure
(def abc-u (trace-of abc* [] {:a false :c true}))

[(gfi/project abc-u (sel/select :c))
 (gfi/project (trace-of abc [] {:a false :c true}) (sel/select :c))]
;=> [-2.0794 -2.3026]
```

Here gen.clj departs from the thesis. Eq. 4.1 lets the new run drop
choices the selection did not name ($B \subseteq A_\sigma$). gen.clj's
override keeps every unselected choice, and a move that would drop one is
a loud error: selecting $a$ alone, a move to $a$ false would drop $b$.
Selecting the choices that $a$ decides, as above, avoids it:

<!-- code: abc-drop -->
```clojure
;; error: regenerate leaves an unselected choice unvisited
(mapv #(gfi/regenerate abc-t (sel/select :a) %) (rng/split (rng/key 16) 30))
```

### The optimal internal proposal

The best internal proposal is the conditional itself, $q(\upsilon; x,
\sigma) = p(\upsilon \mid \sigma; x)$ (p. 145). Then `generate`'s weight
is $\log \bar p(\sigma; x)$ whatever it draws, and `regenerate`'s is
$\log \bar p(\tau|_{S^{\mathsf{c}}}; x') / \bar
p(\tau'|_{S^{\mathsf{c}}}; x)$, which is 0 when the arguments stay and
the move keeps the set of addresses. `enum/with-exact-proposal` makes
this proposal for finite choices by enumerating them (*Debugging with
Enumeration*). The enumerated choices must not change the model's
structure, so it needs a model like this sprinkler, whose choices are
always the same three. Every key gives one weight, the log of the
marginal likelihood from the sprinkler's table:

<!-- code: optimal -->
```clojure
(def sprinkler
  (gen []
    (let [rain (trace :rain (d/bernoulli 0.2))
          on (trace :sprinkler (d/bernoulli (if rain 0.01 0.4)))]
      (trace :wet (d/bernoulli (cond (and rain on) 0.99
                                     rain 0.8
                                     on 0.9
                                     :else 0.01))))))

(def sprinkler-table
  (table sprinkler [] (zipmap [:rain :sprinkler :wet] (repeat [true false]))))

(def sprinkler* (enum/with-exact-proposal sprinkler [:rain :sprinkler]))

(def wet (cm/choicemap :wet true))

(mapv #(:weight (gfi/generate sprinkler* [] wet %))
      (rng/split (rng/key 17) 3))
;=> [-0.79147 -0.79147 -0.79147]

(array/allclose? (array/exp (:weight (gfi/generate sprinkler* [] wet
                                                   (rng/key 17))))
                 (marginal sprinkler-table {:wet true}))
;=> true
```

A regenerate of the rain has weight 0, so Metropolis–Hastings accepts
every such move: this is Gibbs sampling. (The thesis writes $\log
w = 1$ for this case, meaning $w = 1$.)

<!-- code: gibbs -->
```clojure
(def wet-t (:trace (gfi/generate sprinkler* [] wet (rng/key 18))))

(mapv #(:weight (gfi/regenerate wet-t (sel/select :rain) %))
      (rng/split (rng/key 19) 3))
;=> [0.0 0.0 0.0]
```

gen.clj's laws come in sets. The general set holds for any internal
proposal: generate's weight is the projection, regenerate's the ratio of
projections. The forward-sampling set adds laws that hold only for
forward sampling. The exact proposal passes the general laws and fails a
forward-sampling one, that generate's weight is the log probability of
the constrained choices, as it should:

<!-- code: optimal-laws -->
```clojure
(def exact-models [["sprinkler*" sprinkler* [] []]])

[(law laws/generate-weight-is-the-projection exact-models 50)
 (law laws/regenerate-weight-is-the-projection-ratio exact-models 50)]
;=> [{:pass? true :num-tests 50} {:pass? true :num-tests 50}]

(:pass? (law laws/generate-weight-is-the-constrained-density exact-models 50))
;=> false
```

## Composition and namespaces

Generative functions compose (§2.1.5). To sequence $\mathcal{P}_1$ and
$\mathcal{P}_2$, run the first and pass its return value to the second.
If their addresses lie in disjoint sets $A_1$ and $A_2$, the sequence is
a generative function with

$$
p_3(\tau; x) = p_1(\tau|_{A_1}; x)\; p_2(\tau|_{A_2}; f_1(x,
\tau|_{A_1})), \qquad f_3(x, \tau) = f_2(f_1(x, \tau|_{A_1}),
\tau|_{A_2}).
$$

In the thesis's example, $\mathcal{P}_1$ draws $n \ge 0$ with probability
$0.5^{n+1}$ and returns $n + 1$, and $\mathcal{P}_2$ flips $x$ with
probability $x/(x+1)$. A splice without an address, Gen.jl's `{*}`, runs
a callee among its caller's addresses, which composes them so. Three
rows of the thesis's table, and the formula on twelve dictionaries:

<!-- code: sequencing -->
```clojure
(def p1
  (gen []
    (+ 1 (trace :n (d/geometric 0.5)))))

(def p2
  (gen [x]
    (trace :x (d/bernoulli (/ x (+ x 1.0))))
    0))

(def p3
  (gen []
    (splice p2 (splice p1))))

(mapv #(density p3 [] %)
      [{:n 0 :x true} {:n 1 :x true} {:n 2 :x false}])
;=> [0.25 0.16667 0.03125]

(defn sequenced
  "p3(τ) by the thesis's sequencing: p1 of tau's :n, times p2 of its :x
   given p1's return value."
  [tau]
  (let [tau1 (select-keys tau [:n])
        x (:retval (gfi/assess p1 [] (cm/from-map tau1)))]
    (* (density p1 [] tau1) (density p2 [x] (select-keys tau [:x])))))

(every? #(array/allclose? (density p3 [] %) (sequenced %))
        (for [n (range 6), x [true false]] {:n n :x x}))
;=> true
```

When both use the address $x$ the construction fails. The thesis's
modeling language requires addresses to be unique (p. 63), and gen.clj
makes a repeated one a loud error:

<!-- code: p1-at-x -->
```clojure
(def p1-at-x
  (gen []
    (+ 1 (trace :x (d/geometric 0.5)))))
```

<!-- code: overlap -->
```clojure
;; error: Address [:x] is used twice
(gfi/simulate (gen [] (splice p2 (splice p1-at-x))) [] (rng/key 20))
```

*Address namespaces* make any two generative functions disjoint: wrap
each address $a$ of a call in the call's token $k$, giving the address
$(k, a)$. A splice with an address does exactly this: the call's choices
lie under its address, and the caller's score is the sum of the calls'
scores:

<!-- code: namespaced -->
```clojure
(def p3-namespaced
  (gen []
    (splice :k2 p2 (splice :k1 p1-at-x))))

(def t3 (gfi/simulate p3-namespaced [] (rng/key 21)))

(cm/addresses (:choices t3))
;=> [[:k1 :x] [:k2 :x]]

(array/allclose? (:score t3)
                 (+ (:score (trace/subtrace t3 :k1))
                    (:score (trace/subtrace t3 :k2))))
;=> true
```

Branching composes too: a generative function that delegates to
$\mathcal{P}_1$ or $\mathcal{P}_2$ by its first argument has $p_1$ or
$p_2$ as its density, and the two may share addresses. gen.clj's Switch
counts branches from 0 and passes the remaining arguments to the branch
it runs:

<!-- code: branching -->
```clojure
(def p1-or-p2 (comb/switch p1 p2))

[(array/allclose? (density p1-or-p2 [0] {:n 2}) (density p1 [] {:n 2}))
 (array/allclose? (density p1-or-p2 [1 3.0] {:x true})
                  (density p2 [3.0] {:x true}))]
;=> [true true]
```

The operations compose as the functions do. Prop. 2.3.2: an update of a
sequence is the update of its first part, then the update of its second
part with the first part's new return value as its argument, and

$$
\log w_3 = \log w_1 + \log w_2, \qquad \sigma'_3 = \sigma'_1 \oplus
\sigma'_2.
$$

Changing both of the namespaced sequence's choices at once, and its two
parts one at a time, gives the same weight and the same discard:

<!-- code: compositional-update -->
```clojure
(def at-1-true
  (trace-of p3-namespaced [] {:k1 {:x 1} :k2 {:x true}}))

(def change (cm/choicemap [:k1 :x] 3 [:k2 :x] false))

(def whole (gfi/update at-1-true change (rng/key 22)))

(def first-part
  (gfi/update (trace/subtrace at-1-true :k1) (cm/get-submap change :k1)
              (rng/key 23)))

(def second-part
  (gfi/update (trace/subtrace at-1-true :k2) [(:retval (:trace first-part))]
              [diff/unknown-change] (cm/get-submap change :k2) (rng/key 24)))

(array/allclose? (:weight whole)
                 (+ (:weight first-part) (:weight second-part)))
;=> true

(= (:discard whole)
   (cm/choicemap :k1 (:discard first-part) :k2 (:discard second-part)))
;=> true
```

This is how combinators update a model without the source code of their
callees.

A generative function may call itself. The thesis's example (p. 62)
flips a coin at go with probability 0.2 of true, and on true calls itself
twice, under the namespaces L and R; it returns the number of calls. The
thesis's table:

<!-- code: recursion -->
```clojure
(def g
  (gen []
    (if (trace :go (d/bernoulli 0.2))
      (+ (splice :L g) (splice :R g) 1)
      1)))

(def g-runs
  [(cm/choicemap :go false)
   (cm/choicemap :go true [:L :go] false [:R :go] false)
   (cm/choicemap :go true [:L :go] true [:R :go] false

(mapv #(let [{w :weight rv :retval} (gfi/assess g [] %)]

;=> [[0.8 1] [0.128 3] [0.02048 5]]
```

The thesis's second version (p. 63) gives up namespaces, which the thesis

## A model as data

A program in a modeling language is text, and a semantic function maps
it to a generative function, written $[\![\mathfrak{p}]\!] = \mathcal{P}$
(§2.2). In gen.clj the program is Clojure data, and `gen` keeps it: a
dynamic generative function's `:source` holds its parameters and its body
as written.

<!-- code: source -->
```clojure
(def program (second (:source burglary-model)))

[(first (:source burglary-model)) (first program)
 (take-nth 2 (second program))]
;=> [[] let [burglary disabled alarm]]

(nth program 2)
;=> (trace :calls (d/bernoulli (if alarm 0.7 0.05)))
```

Fig. 2-1 defines a toy modeling language, with constants, variables,
random choices $\{a\} \sim d(E)$, `let` and `if`, and gives its
denotational semantics by three functions: $\mathrm{Addrs}[\![E]\!]$, the
addresses of a program's choices; $\mathrm{Val}[\![E]\!](\sigma)(\tau)$,
its value given an environment $\sigma$ of variables and the choices
$\tau$; and $\mathrm{Dist}[\![E]\!](\sigma)(\tau)$, the probability of
$\tau$. A program of the toy language is then the tuple $(\mathbb{R}^n,
\mathbb{R}, \lambda x, \tau.\, \mathrm{Dist}[\![E]\!], \lambda x, \tau.\,
\mathrm{Val}[\![E]\!])$. The burglary model's body uses only these
constructs. Transcribed, with a `let` of several bindings read as nested
ones:

<!-- code: toy-semantics -->
```clojure
(defn unnest
  "A toy let of several bindings as nested lets of one binding each."
  [[_ bindings body]]
  (let [[x e & more] bindings]
    (list 'let [x e]
          (if (seq more) (unnest (list 'let (vec more) body)) body))))

(defn toy-addrs
  "Addrs⟦e⟧ (Fig. 2-1): the addresses of the random choices in the toy
   program e."
  [e]
  (cond (and (seq? e) (= 'trace (first e))) (conj (toy-addrs (nth e 2))
                                                  (second e))
        (coll? e) (reduce into #{} (map toy-addrs e))
        :else #{}))

(defn toy-value
  "Val⟦e⟧(env)(τ): the value of the toy program e, its variables bound in
   env, its random choices read from the dictionary tau."
  [e env tau]
  (cond (symbol? e) (env e)
        (not (seq? e)) e
        :else (case (first e)
                trace (tau (second e))
                let (let [[_ [x e1] body] (unnest e)]
                      (toy-value body (assoc env x (toy-value e1 env tau)) tau))
                if (let [[_ test then else] e]
                     (toy-value (if (toy-value test env tau) then else)
                                env tau)))))

(defn toy-dist
  "Dist⟦e⟧(env)(τ) (Fig. 2-1): the probability of the dictionary tau under
   the toy program e. A let or an if gives its first part tau's choices at
   that part's addresses, and its second part the rest of tau; printed?
   gives the second part tau's choices at its own addresses instead, as
   Fig. 2-1 is printed. Distributions are bernoulli's."
  [e env tau printed?]
  (let [parts (fn [e1 e2]
                [(select-keys tau (toy-addrs e1))
                 (if printed?
                   (select-keys tau (toy-addrs e2))
                   (apply dissoc tau (toy-addrs e1)))])]
    (if-not (seq? e)
      (if (empty? tau) 1.0 0.0)
      (case (first e)
        trace (let [[_ a [_ prob]] e]
                (if (= [a] (keys tau))
                  (bern (toy-value prob env tau) (tau a))
                  0.0))
        let (let [[_ [x e1] e2] (unnest e)
                  [tau1 tau2] (parts e1 e2)]
              (* (toy-dist e1 env tau1 printed?)
                 (toy-dist e2 (assoc env x (toy-value e1 env tau)) tau2
                           printed?)))
        if (let [[_ test then else] e
                 branch (if (toy-value test env tau) then else)
                 [tau1 tau2] (parts test branch)]
             (* (toy-dist test env tau1 printed?)
                (toy-dist branch env tau2 printed?)))))))
```

The denotational semantics and `gen`'s, which runs the program, agree on
the burglary model's body: the same addresses, the same probability for
all 81 dictionaries, and the same return value on the support:

<!-- code: toy-check -->
```clojure
(toy-addrs program)
;=> #{:burglary :disabled :alarm :calls}

(every? #(array/allclose? (toy-dist program {} % false) (p %)) (keys p))
;=> true

(every? #(= (toy-value program {} %)
            (:retval (gfi/assess burglary-model [] (cm/from-map %))))
        (support p))
;=> true
```

One change from Fig. 2-1 makes them agree. As printed, the rules for
`let` and `if` give the second part $\tau$ restricted to its own
addresses. A choice that belongs to no part the run takes, such as a
disabled choice on a run without a burglary, then escapes every rule, and
the dictionary that holds it gets the probability of the run without it.
Summed over the 81 dictionaries, the printed rules give 2.982, on 22
dictionaries, and the result is not structured. Giving the second part
the rest of $\tau$, everything outside the first part's addresses, lets
the rules for constants and choices reject an extra choice:

<!-- code: toy-printed -->
```clojure
(def printed (into {} (map (juxt identity #(toy-dist program {} % true)))
                   (keys p)))

[(reduce + (vals printed)) (count (support printed)) (structured? printed)]
;=> [2.982 22 false]

(= (printed {:burglary false :disabled true :alarm false :calls false})
   (printed {:burglary false :alarm false :calls false}))
;=> true
```

So a model is a value in two senses. As a generative function it is an
object that the interface reads, runs and revises without looking inside.
As source it is data that another program can read: here, a semantics of
a page that agrees with `gen` on every dictionary.

## The interface at a glance

The operations, what each returns, where it is defined, and a law that
checks it:

| Operation | Returns | Definition | A law that checks it |
|---------|--------------------------|-----------|---------------------------------------|
| `simulate` | a trace of $\tau \sim p(\cdot\,; x)$ | §2.3.1 | score-is-the-assessed-density |
| `generate` | a trace, $\log p(\tau)/q(\upsilon; \sigma)$ | §4.1.1 | generate-weight-is-the-projection |
| `assess` | $\log p(\tau; x)$, $f(x, \tau)$ | Gen.jl | assess-is-generate-with-every-choice |
| `propose` | $\tau \sim p$, $\log p(\tau; x)$ | Gen.jl | propose-weight-is-the-assessed-density |
| `update` | $\tau'$, $\log p(\tau')/p(\tau)$, $\sigma'$ | Def. 2.3.1 | updates-are-reversible-with-exact-discards |
| `regenerate` | $\tau'$, Eq. 4.1's weight | §4.1.2 | regenerate-weight-is-the-projection-ratio |
| `project` | generate's weight given $\tau\vert_S$ | Gen.jl | generate-weight-is-the-projection |
| gradients | Eqs. 2.11 and 2.12 | §2.3.1 | (in `gen.gradients`'s tests) |

Every inference algorithm in this book is written against these
operations and nothing else. *Inference as Operations on the GFI*, the
next chapter, derives importance sampling, Metropolis–Hastings and
sequential Monte Carlo from the definitions of this one.

## Solutions

**1.** It is the thesis's first distribution that is not structured: the
empty dictionary with probability 0.5, and $\{a \mapsto T\}$ and $\{a
\mapsto F\}$ with 0.25 each. In gen.clj an untraced draw comes from the
trace's encapsulated randomness, which `assess` draws from its key. Key
0's coin makes the choice, so $\{\}$ lacks it and is refused; key 1's
does not, so $\{a \mapsto T\}$ has a choice the run does not make. The
probability of a dictionary is then no function of the dictionary, and
nothing the interface computes from $\tau$ alone, a score or a weight,
means what its definition says:

<!-- code: solution-1 -->
```clojure
(defn assessed
  "assess's probability of the dictionary tau under maybe-traced with the
   key k, or :refused."
  [tau k]
  (try (array/item (array/exp (:weight (gfi/assess maybe-traced []
                                                   (cm/from-map tau) k))))
       (catch clojure.lang.ExceptionInfo _ :refused)))

[(mapv #(assessed {} (rng/key %)) [0 1])
 (mapv #(assessed {:a true} (rng/key %)) [0 1])]
;=> [[:refused 1.0] [0.5 :refused]] ; float64
```

**2.** Every run makes burglary and calls; disabled only after a
burglary, alarm only when the alarm is not disabled. `generate` refuses
$\{\text{disabled} \mapsto T\}$ whenever its run has no burglary, with
probability 0.99, and the 2000 keys agree within five standard errors:

<!-- code: solution-2 -->
```clojure
(mapv #(sound? p {% true}) [:burglary :disabled :alarm :calls])
;=> [true false false true]

(defn refusals
  "How many of n keys make generate refuse the burglary model's
   constraints sigma (a constraint unvisited)."

  (count (filter #(try (gfi/generate burglary-model [] (cm/from-map sigma) %)
                       false
                       (catch clojure.lang.ExceptionInfo e
                         (boolean (:unvisited (ex-data e)))))
                 (rng/split key n))))

(within-5-se? (refusals {:disabled true} 2000 (rng/key 25)) 2000 0.99)
;=> true
```

**3.** The two regenerates are Gibbs moves, each drawing a choice from
its exact conditional given the other and the observation, so the sweep
needs no accept step. The chain's average agrees with the exact
probability within five Monte Carlo standard errors:

<!-- code: solution-3 -->

```clojure
(defn gibbs-sweep
  "Regenerate :rain, then :sprinkler: each move's weight is 0, so each is
   accepted, and the sweep is a Gibbs sweep."
  [tr key]
  (let [[k1 k2] (rng/split key)]
    (-> tr
        (gfi/regenerate (sel/select :rain) k1) :trace
        (gfi/regenerate (sel/select :sprinkler) k2) :trace)))

(def gibbs-chain
  "4000 Gibbs sweeps from wet-t: whether each trace has rain, as 1 or 0."
  (mapv #(if (% :rain) 1.0 0.0)
        (reductions gibbs-sweep wet-t (rng/split (rng/key 26) 4000))))

(def rain-given-wet
  (/ (reduce + (map sprinkler-table (filter #(and (:rain %) (:wet %))
                                            (keys sprinkler-table))))
     (marginal sprinkler-table {:wet true})))

rain-given-wet
;=> 0.3539

(let [{:keys [mean mcse-mean]} (diag/summary gibbs-chain)]
  (< (abs (- mean rain-given-wet)) (* 5 mcse-mean)))
;=> true
```

**4.** The model's `when` and `and` are not toy constructs, but `if` and
a constant do the same work. The parameter `prob-a` is a variable of the
toy program's environment:

```clojure
(def coins
  (gen [prob-a]
    (let [a (trace :a (d/bernoulli prob-a))
          b (if a (trace :b (d/bernoulli 0.6)) true)]
      (trace :c (d/bernoulli (if b 0.9 0.2))))))

(def coins-program (second (:source coins)))

(def coins-table
  (table coins [0.3] (zipmap [:a :b :c] (repeat [true false]))))

(every? #(array/allclose? (toy-dist coins-program '{prob-a 0.3} % false)
                          (coins-table %))
        (keys coins-table))
;=> true
```
